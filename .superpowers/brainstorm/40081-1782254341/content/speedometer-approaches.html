Speedometer Component — 3 Approaches

Click the one that feels right for the Help screen header. Each works on iOS, Android & Web.

A: Classic Speedometer Gauge

Traditional semicircle gauge with a rotating needle. Red → Yellow → Green arc segments. Needle animates with spring physics on mount and when count changes.

Classic feel Reanimated spring SVG paths

B: Modern Arc with Glow

Sleek single arc with gradient fill (red→yellow→green) and a glowing dot indicator. Large number in center. Arc traces smoothly on mount with easing animation. Clean, modern feel.

Modern / minimal SVG gradient + glow Animated stroke

C: Segmented LED Meter

30 individual bar segments arranged in a semicircle — one per contact. Segments light up sequentially with a cascade animation. Red (1-10) → Yellow (11-20) → Green (21-30). Each new contact triggers one more segment to light up.

Gamified / retro Cascade animation 1 segment = 1 contact

All approaches share:

  • react-native-svg for cross-platform rendering (iOS, Android, Web)
  • react-native-reanimated for smooth 60fps animations
  • Motivational text below ("Keep going!" / "Super-Connector!" at 30)
  • Standalone component in src/components/SuperConnectorGauge/
  • Contact count from Redux store
